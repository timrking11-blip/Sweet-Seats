# Existing Sweet Seats visual contexts

## Discovery demo

The existing discovery app is a data-forward interface on the canonical
Midnight Session palette. Its visual patterns prioritize readable event
information, source context, freshness, and truthful unavailable/partial states.
The design system extracts only shared primitives and foundations; it does not
copy discovery page structure.

## Coming-soon brand page

The coming-soon page is a separately imported Lovable marketing composition.
It remains a distinct route and one-time import, not an active sync target. The
design system records the shared brand foundations without re-composing that
page or claiming a connected waitlist.

## Scope

This system provides tokens and shared controls for future review. It has not
been applied to either existing screen, and the derived light palette has not
been approved for product use.
