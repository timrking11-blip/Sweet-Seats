# Button

## Source

- Shared class family: `.ss-button`, `.ss-button--primary`, and
  `.ss-button--quiet` in `lib/sweet-seats-brand/controls.css`.
- Active usage: discovery homepage, discovery list and error states, not-found
  page, reference style guide, and imported coming-soon homepage.

## Preserved behavior

- Native `<button>` semantics, including the native disabled state.
- Primary coral treatment and quiet secondary treatment.
- Minimum 44px target, visible keyboard focus, and reduced-motion behavior.
- Variant prop: `primary` or `quiet`; quiet is the default.

The story is a visual reference only. It does not save events, submit forms,
manage alerts, or buy tickets.
